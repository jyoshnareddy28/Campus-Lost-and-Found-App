# Campus-Lost-and-Found-App
FindIt – Campus Lost and Found App

1. Application Name

FindIt – Campus Lost and Found App

2. Project Topic

Flutter Application Development – Campus Lost and Found Management System.

3. Project Description

FindIt is a Flutter-based mobile application designed to help college students report, search, and recover lost or found items within their campus.

Students can register or log in, report lost and found belongings, view available item reports, check item details and locations, and manage their personal profiles through a simple and user-friendly interface.

4. Technologies Used

- Flutter
- Dart
- Provider (State Management)
- Material Design 3

5. Application Features

- User Login and Registration
- Home Screen displaying lost and found items
- Filter items by All, Lost, and Found
- Add new Lost or Found reports
- Categorize reported items
- View item details and locations
- My Reports section
- User Profile and Logout

7. Data Source Used

The current application uses sample, predefined item records stored in memory through the Provider state management package.

New reports are added dynamically during the application session. No external database or backend service is currently integrated.

8. Steps to Run the Project

Prerequisites:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android SDK or an Android device

Execution steps:

1. Clone the repository:
   "git clone https://github.com/jyoshnareddy28/Campus-Lost-and-Found-App.git"

2. Open the project folder in Visual Studio Code.

3. Install project dependencies:
   "flutter pub get"

4. Run the application:
   "flutter run"
